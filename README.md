# 📘 SocialBook - Social Media UI Clone

A responsive front-end clone of a social media platform built using **HTML, CSS, and JavaScript**.  
This project simulates a basic layout of a modern social network interface, including **Home page** and **Profile page**.

## 🌐 Live Demo

👉 [View Live Project](https://stellular-klepon-37d914.netlify.app/)

## 📄 Pages

- 🏠 **Home Page** – Timeline layout with:
  - Status update box
  - Friend requests, messages, and notifications icons
  - Online friends sidebar
  - Dark mode toggle
  - Responsive layout

- 🙍‍♀️ **Profile Page** – User profile layout with:
  - Cover photo and profile picture
  - Bio and social links
  - Photo grid
  - Friend list
  - Timeline posts

## 💡 Key Features

- ✅ Fully responsive layout (mobile & desktop)
- 🌙 Dark mode toggle
- ⚙️ Settings menu
- 📋 Profile information section
- 🧑‍🤝‍🧑 Online friends list
- 🔄 Navigation between pages

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
